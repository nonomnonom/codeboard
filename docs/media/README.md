# Curated showcase assets

`lengkap-storyboard.png` and `lengkap.mp4` are rendered from [the LENGKAP authoring source](../../examples/lengkap.ts). Original artwork and Foley are CC0-1.0; the film contains no generated images or third-party audio.

To update them, render and visually inspect `codeboard run examples/lengkap.ts --movie`, then explicitly copy the approved `lengkap-storyboard.png` and `lengkap.mp4` from `examples/output/lengkap/` here. Check the movie remains 1920 × 1080, 24 fps, 360 frames and exactly 15 seconds. Fonts are not bundled.
