# Make editable artwork with Codeboard

Draw an illustration, develop a storyboard, or animate a short scene with JavaScript or TypeScript. You can write the code yourself or ask a coding agent to run it. Save the artwork as a `.cboard` project, review a rendered image, and keep revising.

The guides describe the framework's public operations, object model, timing and file formats. Each task works with artwork you create or open in your own project.

## Make your first drawing

1. [Install Codeboard](start/installation.md).
2. [Draw and save your first stroke](start/first-drawing.md).
3. [Review the image and revise the project](workflow/review.md).

Using an agent? [Set up the Codeboard skills](start/agent-setup.md), then [give it a drawing brief](workflow/working-with-an-agent.md). If you prefer to write the script, use the [TypeScript setup](start/typescript.md).
