# Delivery types

Data shapes for delivery. See [all type groups](../types.md) for other domains and shared units. Import public types from `codeboard-studio`; helper shapes are included to explain nested values.

## SheetOptions

```ts
export interface SheetOptions {
    columns?: number;
    rows?: number;
    pageWidth?: number;
    pageHeight?: number;
    margin?: number;
    gutter?: number;
    captionHeight?: number;
}
```
