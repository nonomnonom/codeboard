# Codeboard demo assets

The 48-second `walkthrough.mp4` is a historical showcase rendered with Codeboard v0.2.1. Its terminal scenes are scripted. The soundtrack is original synthesized Foley (CC0-1.0), without third-party music. It is not a v1 verification artifact.

The eight-second `clawd.cboard` and review images come from [the performance study](../../../../examples/code-board-demo/README.md). Current source downloads live under `art/examples/` and include the matching engine. Regenerate those downloads with `node scripts/package-examples.mjs`.
